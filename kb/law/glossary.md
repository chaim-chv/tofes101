# Glossary

Hebrew → English, with the legal meaning that matters for the 101. Keep the Hebrew
term in the UI; use the English for code/docs.

## Core form terms

| Hebrew | English | Meaning |
| --- | --- | --- |
| טופס 101 / כרטיס עובד | form 101 / employee card | the annual employee declaration to the employer |
| 0101/130 | form code | the official form number |
| מעסיק | employer | the person paying the salary/pension |
| עובד | employee | the person receiving it |
| משכורת | salary | work income, pension, severance, scholarship, etc. (broad definition in the form notes) |
| שכר עבודה | wage | daily/hourly wage, especially “עובד יומי” |
| קצבה | pension | periodic pension payment; some are exempt |
| מלגה | scholarship | grant/prize/exemption for a student or researcher |
| תיק ניכויים | deduction file | employer’s tax-withholding account number (9 digits, usually starts with 9) |
| ניכוי במקור | withholding at source | the employer’s duty under s. 164 |
| מס הכנסה | income tax | the tax on income |
| שנת מס | tax year | the calendar year, 1 January–31 December |
| הצהרה | declaration | the employee’s truth statement + 7-day change undertaking |
| חתימה | signature | employee’s signature; employer e-signature only in the approved electronic route |

## Credit terms

| Hebrew | English | Meaning |
| --- | --- | --- |
| נקודת זיכוי | credit point | annual tax reduction unit; 2,904 ₪/yr in 2025–2026 |
| זיכוי | credit | subtracts from tax |
| פטור | exemption | removes income from tax up to a ceiling |
| מדרגת מס | tax bracket | marginal rate band |
| מס שולי | marginal tax | the rate on the next shekel |
| מס יסף | surtax | 3% above 721,560 ₪ (+2% capital) |
| תקרת פטור | exemption ceiling | maximum exempt income (e.g. disability) |
| תושב ישראל | Israeli resident | tax resident; gets the 2.25 base |
| תושב חוץ | foreign resident | non-resident; no 2.25 |
| עובד זר | foreign worker | permit-based worker; special point table |
| עולה חדש | new immigrant (oleh) | s. 35 credit track |
| תושב חוזר | returning resident | separate/overlapping track; see node |
| הורה יחיד | single parent (other parent dead/unknown) | +1 point |
| משפחה חד־הורית | single-parent family | +1 point; includes divorced/separated/widowed/single |
| בן זוג רשום | registered spouse | married spouse for tax purposes |
| ידועים בציבור | unmarried cohabitants | not “married” for the dependent-spouse credit |
| מזונות | alimony / support | spousal alimony (s. 40א) vs child support (children/single-parent rules) |
| ילד נטול יכולת | child without capacity | s. 45 disabled-child credit (2 points) |
| הורה במשפחה חד־הורית החי בנפרד | single parent living apart | item 6 |
| פרוד/ה | separated | requires assessor approval |

## Withholding and coordination

| Hebrew | English | Meaning |
| --- | --- | --- |
| תיאום מס | tax coordination | allocating income/credits across payers |
| טופס 116 | form 116 | the coordination application (not 119) |
| טופס 119 | form 119 | academic/profession credit declaration |
| טופס 106 | form 106 | annual employee statement (by 31 March) |
| טופס 126 | form 126 | employer’s annual report (by 30 April) |
| טופס 101ג | form 101c | shortened pensioner version |
| מעסיק עיקרי | main employer | the payer of the main salary/pension |
| משרה נוספת | additional job | >5 h/day on top of another salary/pension |
| משכורת חלקית | partial salary | ≤5 h/day, or >5 h but <8 h/week |
| עובד יומי | daily worker | <18 days/month but ≥8 h/week |
| שיעור מס מרבי | maximum rate | 47% top rate when the form is missing/invalid |
| אישור פ״ש | assessor approval | needed for “פרוד/ה”, coordination, some exemptions |
| טופס 1312א | form 1312a | locality/settlement approval |
| טופס 116א | form 116a | disabled-relative/institution-care claim |
