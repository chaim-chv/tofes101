# Parents’ credit-point table

11.5.2026. Confirms the 2024–2026 amounts: married woman 2.5 (birth), 4.5 (1–2),
3.5 (3), 2.5 (4–5), 2 (6–17), 0.5 (18); married man 2.5 / 4.5 / 3.5 / 2.5 / 1 /
