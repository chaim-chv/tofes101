# Accessibility coordinators — public list

Every government ministry publishes a named accessibility coordinator. The page
resolves to a dynamic collector listing them, and is the model for the
"רכז נגישות" block our statement must contain when the operator is obligated to
appoint one.

Establishes: the coordinator is a **named person with public contact details**,
not a generic "contact us" form. The regulation ([[source/israel-regs-service-accessibility]],
reg. 90) requires name + office + contact channels.
