# What's new in WCAG 2.2

The nine new success criteria since 2.1, with plain-language intent:

| SC | Level | One-line intent |
| --- | --- | --- |
| 2.4.11 Focus Not Obscured (Minimum) | AA | focused component not *entirely* hidden by author content (sticky header/footer) |
| 2.4.12 Focus Not Obscured (Enhanced) | AAA | not hidden at all |
| 2.4.13 Focus Appearance | AAA | ≥2px perimeter equivalent, 3:1 change |
| 2.5.7 Dragging Movements | AA | every drag has a single-pointer alternative |
| 2.5.8 Target Size (Minimum) | AA | 24×24 CSS px, spacing exception |
| 3.2.6 Consistent Help | A | help mechanism in the same relative order across pages |
| 3.3.7 Redundant Entry | A | auto-populate or let the user select prior answers |
| 3.3.8 Accessible Authentication (Minimum) | AA | no recall/transcription puzzle |
| 3.3.9 Accessible Authentication (Enhanced) | AAA | also no object recognition |

Also confirms 4.1.1 Parsing is removed and that 2.2 pages conform to 2.0/2.1.
