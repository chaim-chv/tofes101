# Kol Zchut — dependent spouse

One point where the taxpayer supports a spouse, only for **married** couples (not
unmarried cohabitants), and only if the taxpayer or spouse has reached retirement
age or is blind/disabled per s. 9(5). On a separate computation only half a point.
Value 242 ₪/month (2026).
