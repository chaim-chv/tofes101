# בדיקת מסך

לכל מסך חדש או ששונה. 15 דקות, בלי חריגים.

## 1. המסך הראשון (30 שניות)

- [ ] ברור **מה השאלה** מהכותרת, בלי לגלול.
- [ ] ברור **מה יקרה** אחרי הלחיצה.
- [ ] יש דרך חזרה גלויה.
- [ ] אין יותר מ-8 שדות גלויים.
- [ ] אין מודאל, קרוסלה, או וידאו אוטומטי.

## 2. עין (2 דקות)

- [ ] היררכיה: `h1` אחד, כותרות משנה, לא שלוש פעמים אותו גודל.
- [ ] יישור ל-`start`; אין טקסט "מרחף".
- [ ] ניגודיות: טקסט 4.5:1; גבולות 3:1.
- [ ] מצב שגיאה נראה אחרת **גם** בלי צבע (אייקון/טקסט).
- [ ] כפתור ראשי אחד; אחרים משניים.
- [ ] אייקוני כיוון נכונים ל-RTL.
- [ ] מספרים וסכומים לא "רוקדים" (tabular).

## 3. מקלדת (3 דקות)

- [ ] `Tab` מההתחלה: סדר הגיוני, אין קפיצות.
- [ ] הפוקוס נראה בכל רכיב, גם על רקע כהה.
- [ ] `Enter` מפעיל את הפעולה הראשית.
- [ ] `Esc` סוגר overlay ומחזיר פוקוס.
- [ ] אפשר להשלים את המסך בלי עכבר.
- [ ] אין מלכודת ואין `tabindex>0`.

## 4. קורא מסך (3 דקות)

- [ ] הכותרת מוקראת ראשונה, ואחריה ההינט.
- [ ] כל שדה: תווית, סוג, חובה/רשות, הינט.
- [ ] שגיאה: מוכרזת, ואומרת מה לעשות.
- [ ] שינוי דינמי מוכרז (שדות חדשים, שמירה).
- [ ] מספרים בעברית: ת"ז/טלפון ספרה-ספרה.
- [ ] אנגלית מוגהית נכון (`lang="en"`).

## 5. מובייל (3 דקות)

- [ ] 360px: אין גלילה אופקית.
- [ ] מקלדת פתוחה: השדה הממוקד נראה; הסרגל לא מכסה.
- [ ] יעדים ≥44px; לא לחיצים צמודים.
- [ ] `inputmode` נכון לכל שדה.
- [ ] סרגל תחתון עם safe-area.
- [ ] סיבוב מסך לא שובר.

## 6. תוכן (2 דקות)

- [ ] כל משפט ≤15 מילים; אין ז'רגון בלי הסבר.
- [ ] מונחים עקביים עם הטבלה ב-[[ux/hebrew-microcopy]].
- [ ] הודעות שגיאה נוסח "מה לעשות", לא "שגיאה".
- [ ] אין placeholder בתור תווית.
- [ ] אין "אופס", "משהו השתבש", סימני קריאה.

## 7. פרטיות (1 דקה)

- [ ] אין בקשת רשת עם נתוני טופס (DevTools → Network).
- [ ] אין PII ב-URL.
- [ ] אם נשמרת טיוטה — יש אזהרה והיא מובנת.
- [ ] מצב מכשיר משותף זמין.

## 8. הגדרות קיצון

- [ ] 200% zoom.
- [ ] `prefers-reduced-motion: reduce`.
- [ ] Windows High Contrast.
- [ ] JavaScript מושבת (אם רלוונטי): לפחות הודעת שגיאה קריאה.
- [ ] טופס עם 0 ילדים / 10 ילדים.
- [ ] שם עם 40 תווים, תווים ערביים, מקף.
- [ ] ת"ז עם אפסים מובילים.
- [ ] טלפון בפורמט `+972`.

## 9. צילום מצב

- [ ] צילום מסך של מצב שגיאה מצורף ל-PR.
- [ ] צילום של 360px.
- [ ] צילום של מצב הפוקוס.
