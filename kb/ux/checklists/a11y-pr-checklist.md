# צ'קליסט PR

סמנו רק מה שבדקתם בפועל. "N/A" מותר עם נימוק. כל שורה ממופה לקריטריון.

## סמנטיקה ומבנה

- [ ] `lang="he" dir="rtl"` על `<html>`; `lang="en"` על טקסט אנגלי (3.1.1/3.1.2)
- [ ] `<h1>` אחד; כותרות בסדר יורד, בלי דילוג (1.3.1, 2.4.6)
- [ ] `<main>`, `<nav>`, `<header>`, `<footer>` — landmarks (1.3.1)
- [ ] אין תוכן משמעותי ב-`::before/::after` או ברקע CSS (1.1.1)
- [ ] כל `<img>` עם `alt`; דקורטיבי `alt=""` (1.1.1)
- [ ] טבלאות עם `<th scope>` ו-`<caption>` (1.3.1)

## טפסים

- [ ] לכל שדה `<label for>` גלוי; אין placeholder בתור תווית (3.3.2)
- [ ] `autocomplete` לכל שדה מידע אישי (1.3.5)
- [ ] `inputmode` מתאים; אין `type="number"` לת"ז/טלפון
- [ ] `required` על חובה; "רשות" מסומן בטקסט (3.3.2)
- [ ] קבוצות רדיו/צ'קבוקס ב-`fieldset`+`legend` (1.3.1)
- [ ] הינט מקושר ב-`aria-describedby` (3.3.2)
- [ ] שגיאה: `aria-invalid="true"` + טקסט + קישור מהסיכום (3.3.1/3.3.3)
- [ ] סיכום שגיאות מקבל פוקוס; כל קישור ממוקד לשדה (3.3.1)
- [ ] אין איפוס/מחיקת נתונים אחרי שגיאה (3.3.3)
- [ ] כפתור שליחה לא מושבת בלי הסבר (3.3.1)

## מקלדת ופוקוס

- [ ] כל פעולה ניתנת לביצוע במקלדת (2.1.1)
- [ ] אין מלכודת פוקוס; `Esc` סוגר overlay (2.1.2)
- [ ] אין `tabindex` חיובי (2.4.3)
- [ ] סדר פוקוס תואם DOM וסדר חזותי ב-RTL (2.4.3)
- [ ] פוקוס נראה: 2px+, ניגוד 3:1 (2.4.7; 2.4.13)
- [ ] פוקוס לא מוסתר על ידי sticky (2.4.11)
- [ ] קישורי דילוג לתוכן ולניווט (2.4.1)
- [ ] קיצור מקש בודד ניתן לכיבוי/שינוי (2.1.4)

## RTL ו-bidi

- [ ] אין `left/right` פיזי בפריסה; נכסים לוגיים (1.3.1)
- [ ] אייקוני כיוון מתהפכים; לוגו/עין/שעון לא (1.3.3)
- [ ] ת"ז/טלפון/אימייל/URL עטופים `dir="ltr"` (1.3.1)
- [ ] טקסט משתמש מוצג עם `bdi`/`dir="auto"`
- [ ] מספרים בטבלאות עם `tabular-nums`; אין היפוך עמודות ידני

## ויזואל

- [ ] ניגודיות 4.5:1 לטקסט, 3:1 לטקסט גדול (1.4.3)
- [ ] ניגודיות 3:1 לגבולות רכיבים ואייקונים (1.4.11)
- [ ] צבע אינו האמצעי היחיד (1.4.1)
- [ ] 200% zoom בלי חיתוך (1.4.4)
- [ ] 320px / 400% בלי גלילה אופקית (1.4.10)
- [ ] text-spacing מוגבר לא שובר (1.4.12)
- [ ] אנימציות מכבדות `prefers-reduced-motion` (2.3.3)

## מובייל ומגע

- [ ] יעדים ≥44×44 (2.5.8 דורש 24)
- [ ] אין zoom lock; `font-size` ≥16px בשדות
- [ ] מקלדת וירטואלית לא מכסה את השדה הממוקד (2.4.11)
- [ ] סרגל תחתון עם `safe-area-inset`
- [ ] גרירה (אם יש) עם חלופת לחיצה (2.5.7)

## תוכן והודעות

- [ ] הודעות שגיאה אומרות מה לעשות (3.3.3)
- [ ] עברית פשוטה; אין מונח משפטי בלי הסבר (3.1.5)
- [ ] `aria-live` רק לאזור סטטוס אחד (4.1.3)
- [ ] "נשמר"/"נרשם" מוכרזים בלי להזיז פוקוס (4.1.3)
- [ ] הצהרת החתימה מוצגת במלואה (לא מקופלת)

## אבטחה/פרטיות (חוצה)

- [ ] אין בקשת רשת עם נתוני טופס
- [ ] אין PII ב-URL/שם קובץ/מטא-דאטה
- [ ] מצב מכשיר משותף לא שומר טיוטה

## הרצה

- [ ] axe: 0 serious/critical
- [ ] מקלדת בלבד: שלב שלם
- [ ] קורא מסך: המסך שהשתנה
- [ ] 320px + 200%
- [ ] צילום מסך של מצב השגיאה ב-PR

## בלוק להעתקה

```md
- [ ] keyboard-only step completes; focus visible; no trap
- [ ] SR pass (NVDA/VoiceOver) on changed screen
- [ ] labels + autocomplete + inputmode
- [ ] error summary focuses + links focus fields
- [ ] RTL/bidi: IDs, phones, emails isolated
- [ ] axe 0 serious/critical
- [ ] 320px / 200% / zoom
```
