# הדפסה וייצוא

## מה המשתמש באמת צריך

1. **קובץ שמעסיק יקבל** בלי לשאול שאלות (PDF בשם נורמלי, עמודים מסודרים).
2. **עותק לעצמו** (ארכיון, הגשה לרשות המסים).
3. **אפשרות להדפיס ולחתום ביד** אם המעסיק דורש.

## מסלול

```
סקירה → תצוגה מקדימה (HTML, כמו שיודפס) → הורדת PDF / הדפסה
```

- **תצוגה מקדימה קודמת להורדה** — המשתמש רואה בדיוק מה ייצא.
- כפתור "הורדת PDF" + "הדפסה" + "שליחה במייל" (mailto, בלי קובץ).
- שם קובץ: `tofes-101-2026-<שם משפחה>.pdf` — **בלי ת"ז**.

## CSS להדפסה

```css
@page { size: A4; margin: 18mm 16mm; }
@media print {
  nav, .actionbar, .skip, .no-print { display: none !important; }
  body { font-size: 11pt; color: #000; background: #fff; }
  h1, h2 { break-after: avoid; }
  .section { break-inside: avoid; }
  .signature { break-inside: avoid; }
}
```

- עמוד 1: פרטים; עמוד 2: הצהרה + חתימה (לא לשבור).
- מספרי עמודים "עמוד X מתוך Y" — דרך `@page` או מנוע ה-PDF.
- כותרות אמיתיות (`h1/h2`), לא תמונות של טקסט.
- טבלאות עם `<th scope>` — גם להדפסה וגם לקורא מסך.

## נגישות ה-PDF

ת"י 5568 **חלק 2** עוסק במסמכים דיגיטליים ([מקור](../sources/govil-is5568-standard.md)).
`confidence: likely` לגבי מידת העמידה של מחוללי PDF בדפדפן — יש לבדוק.

מינימום שאנחנו מחויבים בו:

| דרישה | איך |
| --- | --- |
| טקסט אמיתי, לא תמונה | מחולל HTML→PDF או `pdf-lib` עם טקסט |
| תגיות (Tagged PDF) | לא מובטח בכל מחולל; לבדוק ב-Adobe/PAC |
| שפת מסמך | `/Lang (he-IL)` |
| כותרת מסמך | `/Title` בעברית |
| סדר קריאה | DOM order; לא מיקום מוחלט |
| ניגודיות | שחור על לבן כברירת מחדל |
| חתימה | וקטור/תמונה חדה, לא 200px |

אם אי אפשר Tagged PDF: **לא להצהיר** עמידה מלאה בחלק 2; לספק גם HTML
נגיש להורדה, ולציין את החריג בהצהרת הנגישות.

## מטא-דאטה

- `Title`: "טופס 101 — כרטיס עובד — שנת מס 2026".
- `Author`: שם העובד (או "הופק מקומית").
- `Subject`: "טופס 101".
- **לא** לשים ת"ז, כתובת או טלפון במטא-דאטה.

## הדפסה ידנית

- כפתור "הדפסה" קורא ל-`window.print()`.
- לפני: מוודאים שהחתימה נשמרה; אם לא — מזהירים.
- בדיקה: הדפסה ל-PDF בכרום, ספארי, פיירפוקס; A4; שוליים; עברית לא
  נחתכת; טבלאות לא נשברות באמצע שורה.

## Do / Don't

| Do | Don't |
| --- | --- |
| תצוגה מקדימה | הורדה עיוורת |
| PDF עם טקסט | צילום מסך של הטופס |
| שם קובץ בלי ת"ז | `101_123456789.pdf` |
| הצהרה על חריגי PDF | "PDF נגיש 100%" בלי בדיקה |
| חתימה בעמוד 2 | חתימה בעמוד נפרד |
