# 5568 מול WCAG 2.2

## העובדה שקובעת הכול

ת"י 5568 חלק 1 (ספטמבר 2023) **זהה ל-WCAG 2.0 מ-11.12.2008**, למעט תוספות
לאומיות ([מקור](kb/sources/govil-is5568-standard.md)). כלומר:

- היעד החוקי בישראל = **WCAG 2.0 AA**.
- WCAG 2.2 **כולל** את 2.0, ולכן עמידה ב-2.2 מקיימת את 2.0 — אבל לא להפך.
- אסור להצהיר "WCAG 2.2 AA" אם בדקנו רק את 2.0.

## הדלתא שכן משנה לנו (2.0 → 2.2)

| SC | רמה | למה זה קריטי בטופס 101 |
| --- | --- | --- |
| **2.4.11** Focus Not Obscured | AA | סרגל הפעולה הדביק בתחתית המסך לא יסתיר לגמרי את השדה הממוקד |
| **2.4.13** Focus Appearance | AAA | טבעת פוקוס 2px+, ניגוד 3:1 — אנחנו מאמצים גם בלי חובה |
| **2.5.7** Dragging | AA | סידור מחדש של ילדים בגרירה חייב חצים; גם ציור חתימה — יש מסלול לא-גרירה |
| **2.5.8** Target Size | AA | 24×24 מינימום; אנחנו הולכים ל-44×44 במובייל |
| **3.2.6** Consistent Help | A | כפתור העזרה באותו מקום בכל שלב |
| **3.3.7** Redundant Entry | A | לא לשאול שוב שם/ת"ז/כתובת בשלב הסיכום |
| **3.3.8** Accessible Auth | AA | לא רלוונטי כל עוד אין חשבון; אם ייווסף — בלי סיסמה לזכור |
| **2.4.12 / 3.3.9** | AAA | מחוץ לרף; לא להצהיר |

מקור: [W3C What's New in 2.2](kb/sources/w3c-wcag22-whats-new.md).

## מה מ-2.1 שכבר חובה אצלנו (כי 2.2 כולל אותו)

- **1.3.5 Identify Input Purpose** (AA) — `autocomplete` לכל שדה מידע אישי.
- **1.4.10 Reflow** (AA) — 320px, בלי גלילה דו-ממדית.
- **2.1.4 Character Key Shortcuts** (A) — כל קיצור של מקש בודד חייב כיבוי/שינוי.
- **2.5.3 Label in Name** (A) — שם הנגישות מכיל את הטקסט הנראה.
- **4.1.3 Status Messages** (AA) — "נשמר" / "החתימה נרשמה" מוכרזים בלי להזיז פוקוס.

## תוספות לאומיות של 5568

התקן כולל "שינויים ותוספות לאומיים" מעבר ל-WCAG 2.0 — בין היתר חובת
**הצהרת נגישות** ודרישות למסמכים דיגיטליים (חלק 2). את הנוסח המדויק קוראים
בקובץ הרשמי; אל תניחו שהתוספות זהות ל-WCAG. `confidence: verified` לעצם
קיומן, `likely` לתוכן המדויק — יש לבדוק מול ה-PDF לפני הצהרה.

## המדיניות שלנו

1. בונים ומבדקים ל-**WCAG 2.2 AA**.
2. מצהירים בטופס המדויק: "ת"י 5568 (WCAG 2.0 AA)" + "נבדק גם מול WCAG 2.2 AA".
3. שומרים בדיקות 2.2 בצ'קליסט ה-PR, לא רק בדוח השנתי.
