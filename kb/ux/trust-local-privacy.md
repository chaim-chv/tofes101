# אמון ופרטיות

## ההבטחה חייבת להיות מדויקת

| אומרים | מתכוונים |
| --- | --- |
| "הנתונים נשארים בדפדפן" | נשמרים ב-localStorage/IndexedDB במכשיר |
| "אין שרת" | אין בקשה שמכילה תשובות; האתר סטטי |
| "לא רואים מה מילאתם" | למפעיל אין גישה; לדפדפן/מנהל המכשיר יש |
| "אפשר למחוק" | כפתור שמוחק טיוטה + הורדות |

`confidence: likely` לגבי מעמד משפטי תחת חוק הגנת הפרטיות — כלי מקומי עדיין
מעבד מידע אישי על המכשיר; יש לתעד החלטה עם עו"ד. אל תסיקו "אין בסיס נתונים"
בלי בדיקה.

## מה חייב להיות נכון טכנית

1. **אפס בקשות עם נתוני טופס.** בדקו ב-DevTools → Network בכל שלב.
2. **פונטים, אייקונים ו-JS self-hosted.** CDN רואה IP; פונט של Google
   רואה IP ובקשות. היוצא מן הכלל היחיד הוא תג אנליטיקס אחד.
3. **אנליטיקס = צפיות בעמודים בלבד** (Umami): בלי ערכי שדות, בלי
   session replay, בלי fragment או query params, בלי עוגיות, ו-DNT מכובד.
   → [[decision/adr-0008-analytics-umami]]
4. **אין PII ב-URL.** לא `?id=123456789`, לא בשם קובץ ה-PDF.
5. **CSP** ללא `unsafe-inline`; `Referrer-Policy: no-referrer`.
6. **Service worker** — אם יש, לא לקאש תשובות; רק נכסים סטטיים.

```html
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'">
```

## איך מציגים את זה

- **שורה אחת במסך הפתיחה**, לא עמוד משפטי:
  "כל מה שתמלאו נשמר במחשב שלכם בלבד. אנחנו לא מקבלים את הנתונים."
- **מסך "מה נשמר איפה"** עם שלוש שורות: טיוטה (במכשיר), קובץ PDF (במכשיר),
  מייל (נשלח על ידכם).
- **סטטוס שקיפות** (אופציונלי, חזק): כפתור "מה נשלח?" שמציג "0 בקשות".
  אם אין לכם דרך אמיתית להראות — אל תבטיחו.

## מכשיר משותף

```html
<fieldset>
  <legend>מכשיר משותף?</legend>
  <label><input type="radio" name="device" value="private" checked> מכשיר אישי</label>
  <label><input type="radio" name="device" value="shared"> מחשב משותף</label>
</fieldset>
<p class="hint">במצב משותף לא נשמור טיוטה, ונמחק כל מה שהוזן בסגירה.</p>
```

- מצב משותף: `localStorage` לא נכתב, `beforeunload` מנקה, וה-PDF מוצע
  להורדה מיידית.
- **לא** לנקות אוטומטית בלי להגיד — זה אובדן נתונים.
- "מחיקת כל הנתונים" בכפתור, עם אישור הקלדה ("מחק").

## אזהרות שאי אפשר לדלג עליהן

| מתי | הודעה |
| --- | --- |
| מצב פרטי | "בגלישה פרטית הטיוטה עלולה להיעלם בסגירה." |
| ניקוי דפדפן | "ניקוי היסטוריה ימחק את הטיוטה." |
| הורדת טיוטה | "הקובץ מכיל פרטים אישיים. שמרו במקום בטוח." |
| מכשיר משותף | "אל תשתמשו במצב 'מכשיר אישי' במחשב ציבורי." |
| שליחת מייל | "המייל נשלח מהדואר שלכם; אנחנו לא שולחים אותו." |

## מה לא להבטיח

- "מאובטח" בלי הצפנה.
- "אנונימי" — ת"ז אינה אנונימית.
- "לא ניתן לשחזר" — אם השתמשתם ב-localStorage, אפשר.
- "תואם GDPR" — לא רלוונטי ולא נבדק.

## Do / Don't

| Do | Don't |
| --- | --- |
| self-host הכול | Google Fonts / CDN |
| צפיות-עמוד בלבד (Umami) | session replay |
| מצב מכשיר משותף | שמירה שקטה תמיד |
| אזהרה לפני הורדה | קובץ עם ת"ז בשם |
| כפתור מחיקה אמיתי | "ננקה בשבילך" בלי לומר מתי |
