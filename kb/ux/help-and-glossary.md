# עזרה ומילון

## העיקרון

מידע **חובה** (מה השדה, מה נדרש, מה ההשלכה) — גלוי תמיד.
מידע **מסביר** (מה זה "נקודות זיכוי", למה שואלים) — שכבה שנייה, נגישה
במקום קבוע.

## שלוש שכבות

| שכבה | דוגמה | איפה |
| --- | --- | --- |
| 1. תווית + הינט | "מספר תיק ניכויים" + "9 ספרות, מתחיל ב-9" | מתחת לשדה, תמיד |
| 2. "מה זה?" | מונח משפטי | כפתור פותח `details`/דיאלוג |
| 3. מרכז עזרה | מדריך מלא, שאלות | קישור קבוע + `/help` |

## מונחים שדורשים הסבר (101)

- **נקודות זיכוי** — יחידות שמפחיתות מס; לכל תושב/ת תושב יש נקודת יישוב.
- **תיאום מס** — הסדר בין שני מעסיקים/מקורות הכנסה.
- **תושב ישראל** — מבחן מהותי, לא רק רישום.
- **משרה חלקית / שכר יומי / קצבה / מלגה** — משנות את שיעור הניכוי.
- **פרוד/ה** — מצב משפחתי נפרד; דורש אישור פקיד שומה.
- **תיק ניכויים** — מספר המעסיק ברשות המסים.

ההגדרות המשפטיות עצמן שייכות ל-`law/`; כאן רק הקישור וההסבר בשפה פשוטה.

## דפוס "מה זה?"

```html
<button type="button" class="term" aria-expanded="false" aria-controls="cp-def">
  נקודות זיכוי
  <span class="visually-hidden">— הסבר</span>
</button>
<div id="cp-def" hidden>
  <p>נקודות זיכוי מפחיתות את המס שמנכים מהמשכורת. לכל תושב/ת ישראל יש
  לפחות נקודה אחת. <a href="/glossary#credit-points">הסבר מלא</a></p>
</div>
```

```ts
btn.addEventListener("click", () => {
  const open = btn.getAttribute("aria-expanded") === "true"
  btn.setAttribute("aria-expanded", String(!open))
  panel.hidden = open
})
```

- **לא tooltip** למידע חיוני: tooltip לא נגיש במגע, לא נסגר ב-Esc בקלות,
  ונעלם בגלילה (1.4.13 דורש dismissible/hoverable/persistent).
- אם בכל זאת tooltip: `role="tooltip"`, `aria-describedby`, `Esc`, ונשאר
  עד יציאת פוקוס.
- המונח עצמו לא הופך לכפתור אם הוא בתוך תווית שדה — הכפתור **ליד** התווית.

## מרכז העזרה

- `/help` עם תוכן עניינים, חיפוש, וקישור חזרה לאותו שלב (`?from=step-3`).
- כל מסך: קישור "עזרה" באותו מקום (3.2.6 Consistent Help).
- שאלות נפוצות אמיתיות: "האם הנתונים נשלחים לשרת?", "אפשר בלי אפליקציה?",
  "מה עושים עם ה-PDF?", "טעיתי בשנת מס".
- לא לכתוב "לשאלות נוספות צרו קשר" בלי תשובה.

## עומק הקריאה

- הינט: **משפט אחד**, עד 12 מילים.
- הסבר מונח: **2–4 משפטים**, בלי ציטוט חוק.
- מסמך משפטי: link, לא copy-paste.

## Do / Don't

| Do | Don't |
| --- | --- |
| הינט גלוי מתחת לשדה | tooltip כשדה חובה |
| `<details>`/דיאלוג למונח | מודאל אוטומטי |
| קישור "הסבר מלא" | קיר טקסט ליד השדה |
| עזרה באותו מקום | עזרה רק בפוטר |
| עברית פשוטה | ציטוט סעיף בחוק כשדה |
